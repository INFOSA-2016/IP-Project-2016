## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/INFOSA-2016/IP-Project-2016.git
```

### Navigate to a Group Project

Replace `<group-folder>` with the desired group directory.

```bash
cd IP-Project-2016/<group-folder>
```

Example:

```bash
cd IP-Project-2016/group-4
```

Each project folder contains its own source code, assets, and documentation.
